# Audit — measagent.vercel.app — 2026-09-28

Live site plus a local production build of `web/` on port 4402. The real api was **not**
started: avatar pages and the directory were checked against a stub api serving invented
test avatars (`seo-2026/tools/measagent-stub-api.mjs`; none is a real person), so no
database, Bedrock or Resend key was touched and no chat was sent. Compared with
`RESEARCH.md` (2026-09-16). Evidence: `seo-2026/audits/measagent/`.

## Headline

The SEO build of 09-16 is live and clean: 15/15 sitemap URLs 200, canonicals, titles and
descriptions in range, JSON-LD valid, owner links `rel="me nofollow ugc noopener"`,
thin avatars kept out of the sitemap, owner pages `noindex`. What changed is the
**product policy**: since 2026-09-17 any signed-in person's avatar is listed and indexed at
once. The site is also **nearly invisible in AI answers** (5 of 42 answers) and the brand
is ambiguous ("meas agent"; ChatGPT answered about a product called MezAgent).
